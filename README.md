TravelBuddy 🌍✈️

TravelBuddy is an AI-powered travel planning application built with Next.js that helps users create personalized travel itineraries, discover hotels, and get intelligent travel recommendations using Google's Gemini AI.

Features
🤖 AI-generated travel itineraries
🏨 Hotel search and recommendations
📍 Destination planning assistance
🌤 Travel information and guidance
📱 Responsive and modern user interface
⚡ Fast and interactive experience with Next.js
Tech Stack
Next.js
React
TypeScript
Tailwind CSS
Google Gemini AI
Axios

Installation
Clone the repository
git clone https://github.com/Rrohitttt/TravelBuddy.git
Navigate to the project directory
cd TravelBuddy
Install dependencies
npm install
Create a .env.local file and add your API keys
GOOGLE_AI_STUDIO_API_KEY=YOUR_API_KEY
Run the development server
npm run dev
Open
http://localhost:3000
